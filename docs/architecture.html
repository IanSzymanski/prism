03 · Presentation

The brand system

Core is structure; brands are presentation. Core never names a brand (tests/core-brand-free.test.py enforces it). A brand is a Claude Design System plus a Prism profile that maps core roles to the design system's own names.

Resolution, three layers

Claude Design Systemlive source, read as is, never changed; drift warns but builds use the snapshot ↓ mapped by profile.jsonroles.json: 84 roles, 16 required; optional roles fall back along a chain; own- slots for brand-only roles; build theme ↓ pinned to snapshot/sha256-pinned tokens, fonts, assets; every install identical ↓ resolve.js resolved.json + prism.css--prism-* per theme; unmapped required role stops the build
